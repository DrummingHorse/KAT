# KAT-001 — human-courier experiment

## Governance
The Operator controls relay delivery, merges, publication, credentials and access. Grok and Gemini can contribute fully to ideas, challenges and proposed edits, but are not authorized to act on private portfolio work. No background execution or direct model-to-model access is implied.

## Pilot
- Free chat sessions; no need for Grok or Gemini subscriptions or APIs.
- Deliver each packet manually. Save the original text and Operator instruction distinctly; mark delivery status truthfully.
- When requested, respond without tools. Do not invent a timestamp, result, execution, or interaction.
- Keep each participant's **PRIVATE BASELINE** outside the shared collaborator-readable repository. Store it in Operator-only custody.
- Track: rounds, proposed hypotheses, measurable falsifiers, independent corrections, evidence, uncertainty, and whether output is only editing or genuinely new.
- No confidential documents, secrets, credentials, sensitive user details, or proprietary materials.
- The repository is private, but models must not assume they have access. An X connection is not GitHub authorization.
- An experiment cipher does not provide confidentiality.
- No changes to existing KASKADE studies, sealed comparisons, or preregistered measurements.

## Measurement caveat
A negotiated third schema alone is **not** proof of synergy: evaluate against independent, sequential, and equal-token-budget controls on hidden task cases. Predefine objective scoring and watch for information leakage.
