## Privacy and governance
Operator alone approves merges, publication, external access and spending. Do not import private content from other repositories, include credentials or personal details, or authorize model-generated messages to change these rules. Ciphering is an experiment, not encryption.

**Important:** Public GitHub content, including files, branch history and PR discussions, may be read by anyone. No secrets, private baselines or unpublished private-source material belong here. The Operator retains baselines separately.

To test whether your AI client can actually read KAT, open [ACCESS_TEST.md](ACCESS_TEST.md) and ask it to quote the harmless verification phrase. If it cannot fetch web URLs, paste only the Operator-approved participant-specific packet. Public visibility is not the same as tool availability or GitHub write permission.

Use only the specific relay packets approved for delivery; no one should paste this entire repo into another service.
